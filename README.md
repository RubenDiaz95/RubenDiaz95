At **Synkross**, a custom software development agency, we create digital products and integrate AI into both new systems and platforms that are already running.

I work mainly on:

- Web and mobile applications
- AI-based products and tools
- Process automation
- Integrations between services and existing systems
- Prototypes that need to become real products

## 🧪 What I'm tinkering with

I usually have several projects and experiments open at the same time.

I'm interested in exploring how software interacts with the real world, understanding the limits of devices, and finding unconventional ways to solve problems.

> Some problems are solved with code. Others need cables, protocols and a few tests to figure out what's actually going on.
